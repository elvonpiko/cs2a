cs2a

A super minimal, lightweight CS2 server manager — web panel + agent for your existing VPS. One command, interactive setup, done.

$ curl -fsSL https://elvonpiko.github.io/cs2a/install.sh | sudo bash
Adopts your serverDetects the existing CS2 install, unit and server.cfg — nothing clobbered.
Full cosmeticsKnives, gloves and agents per player — synced like the official loadout.
Plugin catalogMetamod, CounterStrikeSharp, WeaponPaints, whitelist — one click each.
Stays lightTwo small Go binaries, SQLite, no containers, no bloat.

Interactive TUI on first run (CasaOS-style). Also available pinned: sudo CS2A_VERSION=v0.1.0 bash after the pipe. Source on GitHub.
