cs2a

A Counter-Strike 2 server manager that stays out of the way

Web panel for admins and players, plus a small agent on the VPS. One command sets it up, discovers what your machine already has, and installs only what is missing.

$ curl -fsSL https://elvonpiko.github.io/cs2a/install.sh | sudo bash
Adopts your serverFinds the CS2 install, systemd unit, game port and RCON password on its own — nothing clobbered.
Plugin catalogMetamod, CounterStrikeSharp, WeaponPaints, MatchZy, retakes and more — one click, always the current release.
Full cosmeticsKnives, gloves and agents per player, per side — synced like the official loadout.
Stays lightTwo small Go binaries and SQLite. No containers, no runtime, no bloat.

Reruns are safe: existing credentials are reused, not rotated. Pin a version with sudo CS2A_VERSION=v0.1.0 bash after the pipe. Source on GitHub.
