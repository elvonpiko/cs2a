Counter-Strike 2 servers, managed simply

Self-hosted, in two small Go binaries. One command installs it; it discovers and adopts a CS2 server your VPS already runs. No containers, no runtime.

$ curl -fsSL https://elvonpiko.github.io/cs2a/install.sh | sudo bash

Prefer to start from source? Clone the repository, read the README and run the same installer from a checkout.

Server — live status, players, updates that wait for an empty server 1 / 6

Reruns are safe: existing credentials are reused, not rotated. Pin a version with sudo CS2A_VERSION=v0.3.2 bash after the pipe. Releases, docs and issues live on GitHub.
